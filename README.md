## Assumptions
- Single default logged-in user; authentication is out of scope.
- Transcription is not performed; transcripts are seeded or uploaded (.txt / .vtt / .json).
- Summaries are seeded, generated by a deterministic mock, or by an LLM when `LLM_API_KEY` is set.
- Media is a placeholder; the player runs a simulated clock when a meeting has no media file.
