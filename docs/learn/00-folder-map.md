- **CONFIG**: small file, know what it does and why it exists.
- **GENERATED/VENDOR**: never read, never edit. Tools create it, or someone else wrote it.

### The three "gotchas" for a MERN developer

1. **No `node_modules` for Python.** `.venv/` is a per-project interpreter + packages. You must *activate* it (`source .venv/bin/activate` / `.venv\Scripts\activate`) or use `.venv/Scripts/python -m …`.
2. **Dependencies and tool config are in different files** (`requirements*.txt` vs `pyproject.toml`). There is no single package.json.
3. **Tailwind v4 has no `tailwind.config.js`.** Look in `globals.css` for `@theme` / tokens.
